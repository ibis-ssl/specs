# Atlas：STM（Main 基板）概要

Atlas は4輪ステアリングの機体である。CM4 から送るパケットの定義は Orion と共通で、定義の正本は [制御パケット](../common/control_packet.md)、関連文書の入口は [CM4 との通信](cm4_interface.md)を参照。

## CM4 との通信

物理通信方式は [システム構成](../common/system_overview.md#cm4-と-main-の通信)に示す SPI の採用予定に従う。速度・モード・転送手順の詳細は、この文書群にはまだ記載していない。

## 記載状況

Atlas の Main 基板・ファームウェアの実装詳細は、この文書群にはまだ記載していない。対象は次のとおり。

- 外部通信・制御周期・起動と校正・保護条件
- 速度指令から各輪の駆動・ステアリングへの変換と制御、オドメトリ
- SPI の送受信、テレメトリ、停止処理
- ブートローダー、ビルド・書込み、モード・LED・診断操作

`orion_*.md` は Orion の実装仕様を記載する。Atlas の実装仕様は、対象ソースと照合して記載する。

2機種の文書一覧は [STM 概要](overview.md) を参照。
